# 💳 Velora Bank – Digital Banking Management System

A full-stack banking web application built using **Angular**, **Flask**, and **SQLite**. The application allows customers to register, log in, view account details, transfer money, and view transaction history. It also includes an admin portal for managing customers and transactions.

## ⚙️ Running Locally

### Clone the repository

```bash
git clone https://github.com/shravya0306/Digital_Banking_Management_System.git
```

### Install frontend dependencies

```bash
npm install
```

### Start Angular

```bash
ng serve
```

Frontend runs at:

```
http://localhost:4200
```

### Start Flask Backend

```bash
cd backend
python app.py
```

Backend runs at:

```
http://localhost:5000
```
